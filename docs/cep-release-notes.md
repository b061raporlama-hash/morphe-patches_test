Cep Patcher is an independent, modified build of Morphe Manager with its own name, application ID and pocket/clock icon. It is not an official Morphe release.

Fixes clocks disappearing after the first feed card. Real YouTube 21.20.405 creates child conversion contexts before the root filter supplies the video ID. Copying the root's current value therefore copied null into the text contexts. Each card-context copy now retains a link to its source, so mounted text can receive an ID bound later in the same card family. Entering a new card from its bare path into `CellType` cuts the previous card's ancestry, even when both cards share a template. Unknown or conflicting identities keep the save button hidden. The regression suite now checks this actual ordering, and the Android UI test creates text before binding the parent ID.

The standard Gradle production patch task ran against the supplied original YouTube 21.20.405 APK with 96 default patches and **Watch later shortcuts** selected. Its 12 DEX files passed SDK verification. That normally generated, locally test-signed APK installed and opened on an Android 15 x86_64 emulator; clocks appeared on different home-feed video cards after six swipes, remained visible at the top of the feed, and appeared on a NASA search result. This checks the full patch generation path, not a class-replacement prototype. The YouTube APK uses a local test key and is not part of the release. No account was signed in.

The released Cep Patcher 1.0.17 APK was also installed and opened on Android 15. Its built-in **Cep Patches** source loaded from the public update feed as version `1.47.0-cep.17`, with 171 patches and 3 supported app targets.

Fixes the **YouTube startup crash in patch bundle cep.14**. The context builder reuses its incoming object parameter as the integer `1023` before returning. The previous hook called `copy(Object,Object)` at that return, so Android rejected the constructor with `VerifyError`. The hook now runs immediately after `Object.<init>`, while its arguments are still valid references. An unexpected constructor layout stops patching instead of emitting an unsafe hook. Per-card identity scopes and density-aware clock dimensions are retained.

The Android 15 release gate loads and executes DEX generated by the actual context-copy patch transformation. It proves that ART rejects the cep.14-style broken constructor, then executes the fixed constructor and build method across 40 copies, verifies payload and logical identity preservation despite parameter reuse, and checks late parent binding and independent scopes. JVM serialization tests also check hook order and rejection of unknown constructor layouts. There are now 219 identity/save regression checks; Android UI tests cover shared templates, text created before identity, recycling, taps and xxhdpi clocks. Litho mount data and network responses in CI are fixtures. SDK DEX checks alone do not prove ART execution. Proprietary YouTube APKs are never included in the source or release.

To apply the clock fix, update Cep Patcher, then patch the original supported YouTube APK again with **Watch later shortcuts** selected and install the newly generated **Cep YouTube** APK over the existing one. Updating only Cep Patcher does not modify an already patched YouTube installation. Keep Cep Patcher's existing signing data so its generated APK can update the prior Cep YouTube installation.

YouTube patched with the built-in source now defaults to **`app.cep.android.youtube`**, with **Cep YouTube** as the default Custom branding name. It installs beside `app.morphe.android.youtube` and the original YouTube. Existing Morphe Manager and Morphe YouTube installations can remain installed. GmsCore keeps its existing identity and can be shared.

Upgrade Cep Patcher over the previous version, then patch the original YouTube APK again. Already generated APKs retain their previous package identity. A manager upgrade refreshes an older embedded Cep bundle offline and migrates an explicitly saved old Morphe clone identity for the built-in source; newer downloaded bundles and private clone names are preserved.

Download `cep-patcher.apk` and install on Android 8.0 or newer. The APK includes **Cep Patches**, containing **Watch later shortcuts**. In expert mode select YouTube, choose a supported original APK, then explicitly select **Watch later shortcuts**. Its dependencies are included automatically. Patch and install the result.

Patch updates use this release's `cep-patches-bundle.json` through the repository's latest-release endpoint. No token is needed to use the public release. The APK is signed with the repository's persistent Cep Patcher key.

Automated checks cover patch regression tests, manager unit tests and lint, APK signature/identity, and actual bundle loading with the manager's Android DEX loader on an Android 15 emulator. The local Android emulator run additionally patched, installed and opened the real YouTube 21.20.405 app and checked feed and search cards. Real account saves, physical phones, root/Shizuku installation and device-specific behavior still require phone testing.

The Android 15 coexistence check installs synthetic Morphe Manager/YouTube fixtures, reproduces the different-key update rejection, then installs a synthetic Cep YouTube APK transformed by the production clone and GmsCore manifest identity code. Both old packages remain installed; the real signed Cep Patcher release is also installed and launched. These fixtures contain no YouTube code and do not substitute for running a real patched YouTube APK.
